# 术语表

## 说明

本术语表收录书中涉及的专业术语、韩语词汇及经济学概念，按类别分组，每组内按拼音/字母顺序排列。韩语原文以韩文字母标注，便于读者进一步检索。

---

## 一、韩国特有经济术语

| 术语（韩语）      | 中文翻译         | 英文                                       | 解释                                                                                                                                     |
| ----------------- | ---------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 88만원 세대       | 88万韩元世代     | 880,000 Won Generation                     | 形容月收入仅88万韩元（约合人民币5,000元）的年轻非正规职工人，出自2007年同名畅销书，反映韩国年轻人低薪困境                                |
| 강남              | 江南             | Gangnam                                    | 首尔江南区，韩国最富裕地区的代名词，房价最高区域，也是教育竞争最激烈的地区                                                               |
| 경제개발5개년계획 | 五年经济发展计划 | Five-Year Economic Development Plan        | 韩国政府从1962年开始实施的国家经济发展规划，共实施七次（1962-1996），是韩国经济起飞的核心政策工具                                        |
| 경제기획원        | 经济企划院       | Economic Planning Board (EPB)              | 韩国负责经济计划制定和执行的核心政府机构（1961-1994），被称为韩国经济奇迹的"司令塔"，后并入企划财政部                                    |
| 금수저/흙수저     | 金汤匙/土汤匙    | Gold/Dirt Spoon                            | 形容出身富裕/贫困家庭的阶层标签，反映韩国社会阶层固化和代际流动性下降的现实                                                              |
| 낙수효과          | 涓滴效应         | Trickle-down Effect                        | 经济增长的好处从富裕阶层逐渐惠及底层的理论，韩国保守派经济政策的理论基础之一                                                             |
| 뉴타운            | 新城镇           | New Town                                   | 韩国城市再开发项目的统称，尤指首尔地区的大规模住宅再开发计划                                                                             |
| 대기업            | 大企业           | Large Enterprise/Conglomerate              | 韩国大型企业集团，通常指财阀旗下企业，与中小企业形成鲜明的薪资和福利差距                                                                 |
| 새마을운동        | 新村运动         | Saemaul Undong (New Village Movement)      | 1970年代朴正熙政府发起的农村现代化运动，通过政府支援和村民自助推动农村基础设施建设和意识改革                                             |
| 세계화            | 世界化/全球化    | Segyehwa (Globalization)                   | 1995年金泳三政府提出的国家战略，旨在全面融入国际社会，推动韩国加入OECD等国际组织                                                         |
| 소득주도성장      | 收入主导增长     | Income-led Growth                          | 文在寅政府（2017-2022）的核心经济政策，通过提高最低工资和扩大福利来刺激消费和经济增长                                                    |
| 수출드라이브      | 出口驱动         | Export Drive                               | 1960-70年代韩国政府强力推动出口的政策总称，包括出口补贴、税收优惠、信贷倾斜等措施                                                        |
| 재벌 (Jaebol)     | 财阀             | Chaebol                                    | 韩国大型家族企业集团（如三星、现代、LG、SK等），由创始家族通过交叉持股控制多元化业务，是韩国经济的支柱也是争议焦点                       |
| 전세              | 全租             | Jeonse                                     | 韩国特有的住房租赁制度，租客一次性支付房价50-80%的大额保证金代替月租，合同到期后退还保证金。近年因房价暴涨和利率变化，该制度面临崩溃风险 |
| 중화학공업화      | 重化工业化       | Heavy and Chemical Industrialization (HCI) | 1973年朴正熙宣布的产业发展战略，集中国家资源发展钢铁、化工、机械、造船、电子、有色金属六大产业                                           |
| 창조경제          | 创造经济         | Creative Economy                           | 朴槿惠政府（2013-2017）提出的经济政策，强调以创意和技术创新驱动经济增长                                                                  |
| 한강의 기적       | 汉江奇迹         | Miracle on the Han River                   | 指韩国从1960年代开始的快速经济增长，人均GDP从不足100美元增长到超过3万美元，被视为20世纪最成功的经济发展案例之一                          |
| 한류              | 韩流             | Hallyu (Korean Wave)                       | 韩国流行文化（K-pop、韩剧、电影、综艺等）在全球范围内的传播现象，始于1990年代末，已成为韩国重要的文化出口产业                            |
| 헬조선            | 地狱朝鲜         | Hell Joseon                                | 韩国年轻人对社会竞争激烈、阶层固化、生活压力巨大的讽刺称呼，反映对社会不公和上升通道堵塞的绝望感                                         |
| 월세              | 月租             | Wolse                                      | 按月支付租金的租赁方式，近年随着全租制度风险增大，月租比例持续上升                                                                       |
| N포세대           | N抛世代          | N-po Generation                            | 放弃恋爱、结婚、生育、人际关系、住房、梦想等多项人生目标的年轻一代，N代表放弃事项的无限增加                                              |
| IMF 사태          | IMF事态/IMF危机  | IMF Crisis                                 | 1997年韩国接受IMF救助的金融危机事件，韩国社会将其视为"国耻"，深刻改变了韩国经济结构和社会心理                                            |

## 二、经济学专业术语

| 术语           | 英文                                        | 解释                                                                                               |
| -------------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 比较优势       | Comparative Advantage                       | 一国相对于他国在生产某种商品上的效率优势，是国际贸易理论的核心概念，韩国出口导向战略的理论基础     |
| 产业集群       | Industrial Cluster                          | 相关产业在地理上集中形成的产业群落，如韩国蔚山重工业区、水原电子产业区、板桥科技谷                 |
| 产业政策       | Industrial Policy                           | 政府为促进特定产业发展而采取的政策措施，包括补贴、税收优惠、贸易保护等，韩国是产业政策的典型实践者 |
| 出口导向工业化 | Export-Oriented Industrialization (EOI)     | 以出口为导向推动工业化的发展策略，韩国从1964年开始采用此战略，成为东亚发展模式的核心特征           |
| 发展型国家     | Developmental State                         | 政府积极干预经济发展的国家模式，通过产业政策、信贷分配等手段引导经济发展方向，韩国是典型代表       |
| 购买力平价     | Purchasing Power Parity (PPP)               | 考虑各国物价水平差异后的汇率调整方法，用于更准确地比较不同国家的实际生活水平                       |
| 基尼系数       | Gini Coefficient                            | 衡量收入分配不平等程度的指标，取值0-1，越接近1表示越不平等。韩国基尼系数约0.33（2022年）           |
| 经常账户       | Current Account                             | 国际收支中商品和服务贸易的收支差额，韩国自1998年以来持续保持经常账户顺差                           |
| 进口替代工业化 | Import Substitution Industrialization (ISI) | 通过国内生产替代进口产品的工业化策略，韩国在1950年代曾短暂采用，后转向出口导向                     |
| 全要素生产率   | Total Factor Productivity (TFP)             | 除劳动和资本投入外的其他因素（技术进步、制度效率等）对产出增长的贡献                               |
| 人口红利       | Demographic Dividend                        | 劳动年龄人口占比高带来的经济增长优势，韩国在1970-2010年间充分享受了人口红利                        |
| 外国直接投资   | Foreign Direct Investment (FDI)             | 外国投资者对本国企业的直接投资，韩国在发展初期限制FDI，后逐步开放                                  |
| 中等收入陷阱   | Middle-Income Trap                          | 发展中国家在达到中等收入后增长停滞的现象，韩国是少数成功跨越中等收入陷阱的国家之一                 |

## 三、政策与制度术语

| 术语               | 解释                                                                                                                        |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 八三措施           | 1972年8月3日朴正熙政府发布的紧急经济措施，冻结企业对私人高利贷的债务，将其转为低息长期贷款，旨在解救负债累累的企业          |
| 碳中和2050         | 韩国2050年实现碳中和的国家战略，2020年宣布，涉及能源转型、产业结构调整、绿色技术投资等                                      |
| 大企业集团限制制度 | 韩国公正交易委员会对大型企业集团（资产5万亿韩元以上）实施的限制措施，包括限制交叉持股、限制债务担保等                       |
| 非正规职保护法     | 2007年实施的法律，规定非正规职工人工作满2年后应转为正式员工，但实际效果有限                                                 |
| 金融实名制         | 1993年金泳三政府实施的金融改革，要求所有金融交易使用实名，打击地下经济和腐败                                                |
| 结构调整           | 1997年金融危机后对金融、企业、劳动、公共四大部门进行的全面改革，是韩国经济转型的关键                                        |
| K-半导体战略       | 2021年韩国政府发布的半导体产业发展战略，计划10年内投入510万亿韩元，巩固存储芯片领先地位并进军系统芯片                       |
| 韩国版新政         | 2020年文在寅政府推出的经济刺激计划，包括数字新政和绿色新政两大支柱，总投入160万亿韩元                                       |
| 三低景气           | 1986-1988年韩国经济繁荣期的特征：低油价、低利率（美元利率下降）、低汇率（韩元相对日元贬值），三重利好推动出口和经济高速增长 |
| 维新体制           | 1972年朴正熙通过"十月维新"建立的威权政治体制，赋予总统几乎无限权力，为推行重化工业化提供了政治保障                          |
| 五年经济发展计划   | 韩国政府从1962年开始实施的国家经济发展规划，共七次：第一次（1962-1966）至第七次（1992-1996），后改为五年经济社会发展计划    |
| 重化工业化宣言     | 1973年1月朴正熙总统宣布的产业发展战略，集中国家资源发展六大重化工业，是韩国产业升级的转折点                                 |

## 四、社会与人口术语

| 术语              | 解释                                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- |
| 超老龄社会        | 65岁以上人口占比超过20%的社会，韩国预计2025年进入超老龄社会，是全球老龄化速度最快的国家                          |
| 合计生育率（TFR） | 一名女性一生中预期生育的子女数量，韩国2023年为0.72，全球最低。维持人口替代水平需要2.1                            |
| 老龄化社会        | 65岁以上人口占比超过7%的社会，韩国2000年进入老龄化社会，仅用17年就进入老龄社会（14%）                            |
| 内卷              | 中国社会用语，指过度竞争导致的无效努力和资源浪费，与韩国的过度竞争文化有相似之处                                 |
| NEET族            | Not in Education, Employment, or Training的缩写，指不就学、不就业、不接受培训的青年，韩国NEET比例约18%（2022年） |
| 人口悬崖          | 人口急剧减少的临界点，韩国2020年首次出现人口自然减少（死亡数超过出生数），被视为进入人口悬崖                     |
| 躺平              | 中国年轻人放弃过度竞争、选择低欲望生活的社会现象，与韩国N抛世代现象类似，反映东亚社会共同面临的青年困境          |
| MZ世代            | 千禧世代（Millennials，1981-1996年出生）和Z世代（1997年后出生）的合称，韩国社会对年轻一代的统称                  |
| YOLO              | You Only Live Once的缩写，强调活在当下、享受生活的态度，在韩国年轻人中流行，反映对传统"延迟满足"价值观的拒绝     |

| 系统半导体     | 与存储芯片相对的非存储类芯片（如处理器、传感器等），韩国正努力从存储芯片向系统半导体领域扩展                                                                   |
