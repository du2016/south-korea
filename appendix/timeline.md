# 韩国经济关键数据年表

## 说明

本年表按时间顺序整理韩国经济发展的关键数据与里程碑事件，为读者提供快速参考。人均GDP数据以当年美元计价，数据来源以世界银行和韩国银行为主。

---

## 经济增长率变迁概览

| 时期      | 年均GDP增长率 | 特征                     |
| --------- | ------------- | ------------------------ |
| 1954-1961 | 4.0%          | 援助依赖型低速增长       |
| 1962-1971 | 8.7%          | 出口导向高速增长启动     |
| 1972-1979 | 9.3%          | 重化工业化推动的高速增长 |
| 1980-1989 | 8.6%          | 稳定化后的持续高增长     |
| 1990-1997 | 7.2%          | 全球化时期的中高速增长   |
| 1998-2003 | 5.1%          | 危机后的恢复性增长       |
| 2004-2015 | 3.5%          | 创新驱动的中速增长       |
| 2016-2023 | 2.3%          | 成熟经济体的低速增长     |

> **数据来源**：世界银行World Development Indicators、韩国银行经济统计系统（ECOS）、韩国统计厅（KOSTAT）、IMF World Economic Outlook Database、OECD Economic Outlook。
> 
> **注**：人均GDP数据为当年美元名义值，不同来源数据可能存在微小差异，本表以世界银行数据为主要参考。部分早期数据（1953-1960）因统计体系不完善，存在估算成分。
